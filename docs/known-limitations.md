# Known limitations

1. **Cloud evidence is version-specific.** The workshop image based on `49651aa-dirty-20261104153034` reached ECS steady state; three-role login, sample import, HSDS reads and one bounded Bedrock maintenance job were verified on 2026-11-04. Later repository changes, including source transports and uploads, still require redeployment and cloud validation. Live feeds/websites, OpenSearch, Textract and real MFA variants have not been fully verified. Local PostgreSQL checks and mocked responses do not establish every cloud behavior.
2. **Workshop account is temporary.** Event region is us-west-2 and spend cap is $500. Service/security restrictions are imposed by the organizer. No resource/endpoint/state stored only in that account is durable after cleanup; follow workshop-aws.md and export before expiry.
3. **Source data quality is visible.** Official schemas replace the old handwritten subset. Invalid objects and dependent children are held; valid independent data is retained. Partial imports must not be represented as fully clean data. Review original-engine core mappings and enriched fields when a partner changes its response shape.
4. **Maintenance accuracy is synthetic.** Existing seeded thresholds are preserved; this is not evidence of accuracy on real websites. Multi-program/multi-location pages need stronger subject-scoping before automated field updates are considered. All AI updates still need human approval.
5. **Live fetch needs further hardening/testing.** JavaScript rendering, anti-bot cases, robots timeout handling, private-network targets and redirect validation are not fully addressed. Keep sample website mode for demos until real fetch boundaries are tested.
6. **OpenSearch is optional and not production-validated.** Its query currently does not reproduce every memory filter/geographic feature, and rebuild deletes the shared index. Keep memory mode initially; add filtered queries and a safe incremental/alias strategy before enabling multiple production writers.
7. **Personal data is outside this event scope.** Existing BRD permits only synthetic/demo seeker data until One Degree completes privacy, retention/deletion, consent and access-audit review.
8. **Auth operation gaps remain.** First-password and common MFA challenges have mocked-response regression coverage. Password recovery, MFA enrollment, challenge variants beyond those supported, rate limiting and real user lifecycle validation need further work. Local accounts are a demo mode; browser tokens remain in localStorage. Use HTTPS before public login.
9. **Jobs survive requests, not every infrastructure failure.** Queued/running/completed/failed status and launch failures are persisted. Task/process termination can leave running status until an operator reconciles it; no general lease/retry/event-driven task-stop reconciler is implemented.
10. **Reports have no per-user deduplication/rate limit.** A report selects a record for the next run and raises a human-review flag even when unchanged pages skip AI. Due records self-size; reported records may exceed that automatic due slice. Explicit admin limits cap the total, leaving remaining reports for later runs. Forced all-record runs can be unbounded; sharding is still deferred.
11. **Not implemented:** spreadsheet adapter, HSDS POST endpoints, cross-source entity deduplication, embeddings/semantic search, removal of resources deleted at source, provider email notifications and multilingual chat.
12. **Infrastructure assumptions need account checks.** Aurora engine version/model availability and account quotas must be confirmed before a plan/apply. IAM provisioning includes broad service permissions in the bootstrap deploy role; organizer guardrails remain authoritative. Production should tighten the deployment policy and Bedrock/Textract resource scopes for the chosen account.
13. **Schedules and scope remain limited.** Local-time context is retained for offset recomputation, but time-zone/daylight-saving behavior needs broader tests. Manual checks and import-triggered checks now drain the corpus backlog, while periodic runs retain their daily budget. Sample evidence supports a bounded pool; this does not provide multi-task sharding or crash recovery at large scale. Existing hours/accessibility comparisons emphasize missing values; changes to already populated fields and verified field coverage need further work. Pages without comparable facts are check_failed, and migration 3 persists the full real-model review hash.
