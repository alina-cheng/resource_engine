# Requirements: Sample data generator

Traces to: BR-14

## User story
As a demo owner, I generate realistic data in the existing source formats to show the application.

## Acceptance criteria (EARS)
1. WHEN run with counts and a seed THE SYSTEM SHALL produce reproducible ODRS and NDP files derived from the supplied samples.
2. THE SYSTEM SHALL add curated scenarios so common demo questions have answers.
3. THE SYSTEM SHALL write website content with seeded discrepancies and failures plus a ground-truth file.
4. THE SYSTEM SHALL write policy documents and seed demo users, requests, documents and API keys.
